2 내 기사문 자기평가 다 했어요 ✓

📝 지금 할 일
  1. 내가 쓴 기사문을 독자가 되어 다시 읽어요.
  2. 평가 기준표를 보고 기준마다 나무·새싹·씨앗을 골라요.
  3. 가장 자신 있는 점과 더 키우고 싶은 점을 써요.

3 글 옮기고 저장하기 다 했어요 ✓

📝 지금 할 일
  1. 태블릿 카메라로 교과서의 내 글을 비추고, 글자 인식(텍스트 추출)을 눌러 복사해요.
  2. 오른쪽 칸에 붙여 넣고, 잘못 인식된 글자만 바로잡아요. (내용은 고치지 않아요!)
  3. 오른쪽 📋 내 글 복사 → 📌 패들렛 열기를 눌러 내 이름 칸에 올려요.
  4. 키위런에 붙여 넣고 저장만 해요. ⚠️ 'AI 피드백 받기'는 내일 눌러요!

📝 지금 할 일

  2. 바꾸고 싶은 평가가 있으면 다시 골라요.
  3. 짝에게 특히 봐 달라고 할 기준을 1개 골라요.

6 짝 첨삭하기 (종이) 다 했어요 ✓

📝 지금 할 일
  1. 짝과 A4 기사문을 서로 바꿔요.
  2. 칠판의 평가 기준표를 보며, 짝의 글을 독자가 되어 읽어요.
  3. 포스트잇에 칭찬 1개, 제안 1개를 써서 붙여요. 제안에는 기준 이름을 넣어요.
  4. 글을 돌려주며 왜 그렇게 썼는지 설명해요.
  5. 받은 사람은 "고마워"라고 말하고, 궁금한 점을 질문해요.

7 짝 vs AI 비교하기 다 했어요 ✓

📝 지금 할 일
  1. 키위런에서 'AI 피드백 받기'를 눌러요.
  2. 기준마다 짝의 포스트잇과 키위런 내용 점수를 보고 표시해요.
  3. 나오는 규칙에 따라 고칠지 정하고, 까닭을 써요.
  4. 재도전 목표와 고칠 계획을 정해요.

⚖️ 비교 규칙

🔴 짝 제안 있음 + AI 나무 아님 → 반드시 고치기
🟡 한쪽만 지적 → 독자 입장에서 판단하고 까닭 쓰기
🟢 짝 제안 없음 + AI 나무 → 그대로
💬 두 의견 모두 내 생각과 다르면 → 까닭 적기

🤖 키위런 '내용 점수' 보는 법

기삿거리·제목·자료: 20점 🌳 나무 · 14점 🌱 새싹 · 8점 🌰 씨앗
본문: 40점 🌳 나무 · 28점 🌱 새싹 · 16점 🌰 씨앗
나무가 아니면 AI가 고칠 점을 말한 거예요. '내용 피드백'에서 그 기준의 고칠 점을 읽어 봐요. 형식 피드백(길이, 독자 나이 등)은 참고만 해요.
